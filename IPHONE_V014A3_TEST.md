# iPhone — v0.14A.3 Steering Test

1. Открыть https://max-driving-lab-steering-a3.maxtrcgi.chatgpt.site в Safari под своим ChatGPT account. На экране должен быть DRIVING LAB v0.14A.3 — Steering Test. Сравнение stable A.1: https://max-driving-lab.maxtrcgi.chatgpt.site . Это разные origin, ранее сохранённые settings автоматически не переносятся: выставить одинаковые touch precision,ABS/TCS,car/road/graphics. Не сравнивать при разных настройках.
2. Highway start внутри потока/начальная скорость; density72/120 кратко проверить, затем для заносов выбрать свободную площадку/меньший трафик. Shadow Predictor оставить Off; никакой активной помощи нет.
3. Малая поправка, обычное перестроение на50/150/200km/h. Оценить сохранение прежней точности. Затем быстрые finger+50→−50 и+100→−100 в обе стороны. Частичный input намеренно остаётся точным/прежним; ускоряется крупный shaped target с большой ошибкой.
4. Умеренный занос в обе стороны, раннее и позднее собственное контрруление, своевременное возвращение к центру. Отдельно осторожно проверить чрезмерное удержание: более быстрый руль может сильнее перебросить автомобиль. Не ждать автоматического спасения.
5. Отпускание пальца, touchcancel/второй палец, пауза/возврат, смена режима/repair/reset: остаточный input должен отсутствовать. Стабильность меню/camera/traffic проверить без изменения их настроек.
6. Сразу после короткого манёвра открыть Pause → Steering trace ·20s, сохранить CSV в Files и передать сюда вместе с shadow CSV при необходимости. Написать iPhone model,iOS,orientation,graphics/FPS показание если доступно,скорость/настройки,описание действия,удачный/неудачный отлов. Данные sim-time не заменяют настоящую sensor/display latency; при необходимости короткая screen recording помогает оценить ощущение задержки.

Ни iPhone performance, ни Safari/WebGL render в этой сессии не подтверждены. Новый адрес/fingerprinted modules исключают смешивание с stable cache; при неправильной версии остановить сравнение и сообщить label/address. Не заменять stable до решения пользователя.
