## Model and boundaries
Per logical `(id,generation)`, seeded hash samples assertiveness around preset centres Calm 0.24, Normal 0.50, Assertive 0.76, plus uniform ±0.14; independent lane discipline is centred 0.55 ±0.20. These are initial game-design assumptions, not measured real-driver distributions. Speed tendency and overtake motivation equal assertiveness, patience is its complement, and cooperation is approximately 0.72 − 0.48 × assertiveness plus ±0.06. Values are bounded to [0,1]. Headway is 1.05 + 0.9 × patience seconds, acceleration comfort 1.1 + assertiveness m/s², braking comfort 2.2 + 0.9 × assertiveness m/s². Existing vehicle type, truck performance/shape, profile speed range, seeded driver identity and hidden generation renewal remain.

Desired speed is multiplied by 0.97 + 0.06 × speed tendency and capped at the existing 44 m/s contract. An initial revision exceeded this bound in the rolling-start regression; the runtime range was corrected without relaxing the assertion. Headway and acceleration/braking affect the existing following model. Patience changes the decision score threshold; cooperation adds a small penalty for a nearby rear vehicle; lane discipline weights return preference. All existing `laneSafe` vetoes including fast player and rear-NPC braking remain in force and no random maneuver is added. Patience is a stable preference, not a timer or persistent maneuver intent. Cooperation is a preference during a driver's own decision, not active gap creation for another driver. Risk tolerance is not independently simulated; no perception, impairment, turn-signal or R3.3/R3.4 implementation is claimed.

R3.1 snapshot exposes actual traits, headway, acceleration/braking parameters and the latest accepted maneuver motivation (`slower_leader` or `cruising_lane`), alongside identity, preset, gap, speed and decision/rejection. Motivation records the latest accepted decision, not an R3.3 persistent intent state. Compact overlay added two trait lines; user iPhone acceptance remains outstanding.
