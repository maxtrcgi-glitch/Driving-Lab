# DriverView A.4.1 — продольная инерция

Подтверждённая причина слабого эффекта A.4: observer передаёт реальные seat accelerations, UI100% действительно даёт gain≈1, пружина и её смещение доходят до итоговой camera transform. Ошибки соединения UI не обнаружено. Но перевод головы при разгоне всего≈9мм, а pitch зависит только от углового ускорения кузова и на установившемся разгоне близок к нулю. На дальних объектах такая трансляция почти незаметна. Это объяснение согласуется с измерениями; субъективная оценка на iPhone остаётся за игроком.

Добавлена независимая пружина longPitch: 2.6Hz, критическое демпфирование, точное решение при постоянной цели на шаге240Hz. Target = −clamp(filtered seat acceleration.z,−12,+12) × .0045rad/(m/s²) × существующий intensity/effect/safety/speed gain. Ускорение+Z даёт отрицательное вращение головы поX (взгляд чуть вверх), торможение−Z — положительное (вниз). Конечный pitch объединяет прежнюю реакцию на angular acceleration и новый longPitch; общий предел±.06rad≈3.44°. Soft saturation longPitch ограничивает амплитуду; это авторская визуальная калибровка, не измеренная биомеханика водителя.

Translation gains, bounds±20/12/30мм, observer filters40/220ms, body horizon stabilization, gaze, FOV, Chase и пользовательский storage key остаются прежними. Новая пружина участвует в reset, mode switch и pause/resume. Off/0% плавно гасят её; Static остаётся контрольным видом. Интенсивность25% по умолчанию сохранена, прежний пользовательский100% не сбрасывается. Камера не меняет Vehicle.

Это не просто увеличение коэффициента перемещения: эффект дополнен независимой ориентацией головы. CSV-подобные JSON rows в reports/head-inertia.json сохраняют raw/filtered seat acceleration, gain, spring target/state/output и final orientation delta. График reports/head-chain.png.
