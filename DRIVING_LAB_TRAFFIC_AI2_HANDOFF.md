## 1. Архитектура и файлы

JavaScript ESM / Three.js r180 / WebGL. Игрок — прежний Vehicle с node-beam физикой240/1920Гц. NPC остаются лёгкими дорожными объектами; отдельного node-beam двигателя для трафика нет.

Рабочий .openai/hosting.json теперь указывает на отдельный Traffic AI Site, а не на контрольную публикацию; исторический baseline manifest сохранён в теге/исходном ZIP.

`dist/highway.js`: детерминированный trafficSeed отдельно от дорожного seed; spawn profiles; laneInfo, laneSafe, accelerationFor, decide; quintic перестроение; barrierContact и crashContacts. `dist/app.js`: выдача нового trafficSeed при обычном старте, фиксированный query-параметр и запись seed/счётчиков в телеметрию; версия0.14A.3.2. `dist/index.html`: метка версии и правильная ссылка standalone теста. `tests/app-bootstrap.mjs`: query/reset/prefs интеграция. Три новых теста traffic-ai2, traffic-player-identity, traffic-performance. package-steering-test создаёт отдельную сборку с уникальной директорией модулей и SHA256-манифестом.

Физика, tyres, ABS/TCS, steering response и outer-reserve mapping, повреждения игрока, камеры, модели, графика и все Shadow/60Гц диагностические модули сохранены. Регрессионная идентичность без внешних контактов проверена. Разница стартовой скорости объясняется новой скоростью окружающего потока; разница после столкновения — новым внешним NPC контактом.

## 2. Логика

Новые случайные условия выбираются только при создании/перезапуске потока. Внутри поездки решения детерминированы и основаны на зазорах/скоростях, без случайных резких действий. Профили cautious/regular/brisk имеют headway1.65/1.38/1.12с и максимальное ускорение1.2/1.5/1.9м/с². Это стили NPC, не три режима физики игрока. Максимальное служебное торможение7м/с². Интервалы начального заполнения60–66м с малой индивидуальной вариацией, доля грузовиков меняется по seed. Длина/масса прежних автомобилей сохранены.

Решение30Гц; кандидаты — соседняя полоса своего направления. Проверяются передний/задний свободный кузовной зазор, относительные скорости за длительность перестроения3.8–4.4с и допустимое торможение. Резервируются обе полосы; движение не отменяется мгновенным перескоком. Скорость прохождения траектории уменьшается ниже8м/с, при остановке боковой прогресс останавливается. Cooldown12–19с подавляет ping-pong. Обгон имеет преимущество в сторону внутренней полосы, возврат наружу только при безопасных условиях и достаточном выигрыше.

Контакты: NPC OBB опирается на дорожную стену и не выходит из своей проезжей части; столкнувшийся NPC движется пассивно с инерцией/трением. Предвыделенный список crashed участников и дешёвая broad phase ограничивают контакты O(K×N), worst case O(N²). Capsule narrow phase изменяет только NPC velocities/yaw; игрок по-прежнему сталкивается старым Vehicle.collideCircle. Ресайкл только вне прежнего окна−260/+1200м; допускается другая свободная полоса своего направления вне видимого окна, когда исходная заполнена. Количество объектов ограничено выбранной плотностью, максимум120.

## 4. Ограничения и продолжение

Сборка экспериментальная до приёмки игроком. NPC аварии приближённые 2D; очень сильный удар может сопровождаться позиционной коррекцией; сложные свалки требуют ручной оценки. Проверки не гарантируют отсутствие аварии при намеренном таране или резком подрезании игроком. Геометрия дороги сохранена. Нулевой глобальный jam показатель не означает запрет естественных локальных замедлений.

Остановиться после этой итерации. Получить от Max оценку естественности, безопасных обгонов/перестроений, аварий и frame pacing, приложить обычную телеметрию с trafficSeed. Следующий ограниченный этап определяет Director по реальным замечаниям. Не возвращаться автоматически к steering/oversteer, не включать Assist и не менять Baseline. GPT-6.1 Sol подходит для локальных исправлений AI/контактов; GPT-6 Sol — регрессии; Luna — документы; Astra нужна лишь для отдельного сложного архитектурного или физического задания, без автоматического переключения модели.

## 5. Как восстановить

All-In-One ZIP содержит source, полную history.bundle с baseline тегом и ветками, отдельный Site bundle, готовый build, отчёты/тесты/evidence, точный RELEASE_RECEIPT и исходный A31 ZIP. В source обычные локальные файлы. Для полной истории: `git clone history.bundle driving-lab`, затем `git checkout work/traffic-ai2`. Прочитать receipt и проверить SHA/тег. `npm run check`, `npm run check:shadow`, `npm run check:predictor`, `npm run check:traffic-ai2`; последний benchmark требует Node `--expose-gc`, скрипт уже использует его. Тесты Traffic AI загружают старый highway из Git-тега, поэтому им нужна история из bundle.

Статический build запускать через HTTP/HTTPS сервер, не file://. Ресурсы Three.js и модели локальные; npm-зависимости для самой игры не нужны. Закрытие чата не заменяет сохранение архива: скачать ZIP и передать полный файл в Director/следующую сессию. Git-коммиты исходного проекта локальные и сохранены в bundle; отдельный test Site repo синхронизирован через Sites. GitHub не использовался.
