# Driving Lab 0.13 — ручная проверка iPhone

Открыть https://max-driving-lab.maxtrcgi.chatgpt.site в Safari; перезагрузить и убедиться, что welcome показывает 0.13 experimental. Начать с Balanced, 28 машин, сухо, штатный config. Не менять физические коэффициенты во время сравнения.

1. Start: Endless highway. Сразу есть скорость (~скорость потока), автомобили рядом, впереди и позади. Без касания педалей посмотреть первые 2–3 с: нет мгновенного удара/переворота. Pause → Telemetry должен показывать 28/28 active/requested.
2. Controls: одновременно газ+руль, тормоз+руль; отпустить пальцы; открыть pause при удержании газа. При resume машина не получает застрявший ввод. Изменить Thumb travel/precision, проверить малые коррекции и полный ход.
3. Density: поставить 72 и вернуться к старту; повторить с 120. Проверить active/requested, нет наложенных машин/вспышек вблизи. Настройка Empty должна показать 0/0. Новые quality/pad/traffic сохраняются после reload.
4. Speed/braking: на безопасном участке разогнаться, обгонять, затем сильно тормозить до остановки. Следующие автомобили тормозят/перестраиваются; поток продолжает проходить. Снова разогнаться. Не ожидать безопасности при намеренном вклинивании в тормозной путь NPC.
5. Modes/cameras: Circuit/test pad/bumps; cockpit/chase/hood/orbit, reset/repair. Смена камеры не должна сама вызвать физическую аварийную реакцию.
6. Tilt: разрешить датчики в Safari, calibrate; смена ориентации/focus должна требовать свежего центра, ввод не зависает. Проверить звук и copy/export telemetry.
7. Long run: 10–15 минут при 120 и Balanced; после 2 км дорога/машины не прыгают. Затем сравнить с Performance. Отметить нагрев, сильные рывки и фактическое изменение качества. Если тяжело — временно 72/42, это ручной выбор, не скрытый cap.

При проблеме: Pause → Telemetry → Mark issue → Last 60 seconds → Copy telemetry/Export file. Копировать до reload/закрытия. Прислать CSV, описание действия, выбранные quality/traffic, screenshot при визуальном дефекте. Для сравнения измерить 28/72/120 по одному минутному заезду при одинаковом качестве после прогрева.

Acceptance: нет JS/fatal/context-lost сообщений, немедленного spawn collision/переворота, stuck input, массового наложения NPC или роста active выше requested; старые режимы работают. Плавность и визуальная GR86 оценивает Max. До этого версия остаётся experimental.
