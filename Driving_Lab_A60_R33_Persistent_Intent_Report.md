## Architecture
A bounded per-driver intention is separate from the existing lateral trajectory. Target identity is id+generation; lookup uses a map populated with the existing lane index. Normal indexed ticks avoid a new all-pairs scan. Existing non-indexed fallback still scans actors, including after streaming changes/crashes; this is not a complete incident-performance audit.
States: CRUISE/FOLLOW → CONSIDER_PASS → WAIT_FOR_GAP → EXECUTE_PASS → PASS_COMPLETE → RETURN_TO_CRUISE. A blocked current NPC leader establishes identity; intent remains while waiting. Existing candidate utility and safety choose the actual lane; intent never bypasses laneSafe, rear braking, player checks, reservations or the existing trajectory abort. Lane completion and actual target pass are separate: actual pass requires unchanged target generation and being ahead by both half-lengths plus5m. Passing suppresses premature return until the target has been passed; normal cruise preference then governs return.
Target disappearance/recycling, irrelevance and abort invalidate the strategy while leaving physical trajectory safety to the existing controller. Timeout is12+18*patience seconds. After abandoning, a3s strategic reconsideration pause prevents immediate re-creation; a new owner generation starts with a fresh intention. R3.2 score/headway/acceleration preferences remain; no new human perception or impairment model. Following tolerance is represented by existing trait utility and the wait timeout, not a new urgency accumulator.

Diagnostics expose state, logical target, waiting time, target lane, last abandonment and pass status. ACTUAL_PASS_COMPLETED and INTENT_ABANDONED supplement prior considered/accepted/start/lane-complete/abort events. The latest accepted-motivation label remains distinct from current strategic state.
